**Software Engineer. Always learning, always building.**

### About Me

I'm a 25-year-old SDE based in Noida, India, building AI-driven products and backend systems in production. I'm most at home inside large codebases: reading code I didn't write, tracing a bug across five services, and figuring out why something was built the way it was.

I like problems that don't have a clean answer yet, and I use what I know about system design (microservices, gRPC, latency, scale) to make them simpler, faster, and easier to live with.

A few things that define how I work:

- I care more about why the code exists than what it does
- I'm a problem solver first, and I'd rather understand a system than patch it
- I learn by applying: every new idea ends up in a real project
- I'm looking to contribute to large codebases, in open source and in client work

Open to freelance work, open-source contributions, and new opportunities. If you have a hard problem in a big codebase, reach me at [palneha1123@gmail.com](mailto:palneha1123@gmail.com) or on [Medium](https://medium.com/@palneha671), where I write about what I'm learning.
